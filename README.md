# SaaS Abonelik Fiyat Sabitleme Servisi (Price Lock Engine)

Bu proje, SaaS/E-ticaret altyapılarında belirli müşteriler için belirli bir süre boyunca (örn: 5 ay sabit 5.000 TL) fiyat sabitleme ve özel ticari anlaşmaları yönetmeye yarayan kural motorunun İş Analizi ve Teknik Tasarım dokümantasyonudur.

## Proje Kapsamı
- Müşteriye özel sabit fiyat tanımlama.
- Süre dolduğunda otomatik olarak standart katalog fiyatına geçiş.
- Edge case (istisna) ve iş kuralları yönetimi.

## Proje İçeriği
- **`/docs`**: BRD (İş Gereksinimleri) ve User Story'ler (Gherkin formatında).
- **`/diagrams`**: Süreç ve Sequence diyagramları (Mermaid.js).
- **`/database`**: ERD ve Örnek SQL şeması.
- **`/api`**: REST API Request/Response tasarımları.
